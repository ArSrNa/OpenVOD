## P0（已全部关闭，2026-09-17 用户拍板）

| # | 问题 | 决议 | 回填 |
|---|---|---|---|
| 1 | EdgeOne Cloud Functions ↔ 内网连通性 | **不通**。分发端数据库访问走公网（强制 TLS）；产品定位为部署者可自带数据库，不做内网依赖；**SCF Docker 容器作为同级部署目标持续就绪**（其下可走 VPC 或公网） | ADR-0003 |
| 2 | Prisma + Bun 兼容性 | 不兼容则**更换 ORM（倾向 Drizzle）**，运行时坚持 Bun | ADR-0004 |
| 3 | CDN / 存储侧签名机制 | **EdgeOne URL 鉴权 TypeA**（控制台配置鉴权密钥与有效时长，分发端持同款密钥生成）；COS 与 EO 之间**私有回源**，COS 保持私有桶 | ADR-0005 / 0006 |
| 4 | 域名与备案 | **已完成** | ADR-0003 |
